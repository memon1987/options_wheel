## Key Decisions & Rationale

- **Synthetic data correction (FC-021) over a UI footnote.** Three options were considered: (a) leave AMD showing −$17k and explain in plan-file only, (b) inject synthetic rows into the canonical data, (c) add a UI footnote without changing data. Chose (b) because per-symbol attribution drives investigation behavior — users *look* at AMD's number to decide whether to dig. A −$17k loss-line that's actually a +$5k profit will repeatedly mislead anyone reviewing the dashboard. The cost: per-symbol total no longer ≈ headline Total Return ($44.9k vs $20.1k), but the headline is sourced from NLV − deposits independently, so it stays correct. Tradeoff explicitly documented in plan.
- **Hypothesis fit test before any data change.** Before injecting the synthetic rows, ran a daily portfolio-P&L hypothesis fit on three scenarios: (A) trust ledger as-is, (B) one silent 1/16 exercise, (C) two silent events. Hypothesis B won decisively (residual gap +$4.5k vs −$5.2k for A and +$15.6k for C). Confirmed *one* event explains the data — no second discrepancy. Decision made on evidence, not intuition.
- **OCC symbol display: stacked under Strike rather than separate column.** Adds info density without adding a new column. The OCC string is monospaced 10px gray under the strike value; clearly subordinate visually but copyable.
- **`paperTrading` flag wired through SymbolDeepDive via the existing `/api/live/account` hook** rather than building a context provider. LayoutV2 already fetches the account; SymbolDeepDive just calls the same hook. Single source of truth, no plumbing.
- **Communication Style rule broadened from questions to questions OR proposals.** Observed during the session that directive-style asks ("lets do X") get treated as instructions rather than open questions, but the user often *wants* pushback on those too. Added trigger to cover both. Also added timing rule (critique *before* execution) and scope rule (substantive decisions only) to prevent over-firing.

## Discoveries

- **Alpaca paper-engine silently skips deep-ITM call exercises in some cases.** `AMD260116C00212500` was $19.29 ITM at expiry. Real-world option exchanges auto-exercise at $0.01 ITM. Alpaca's paper engine produced no OPASN, OPEXP, OPTRD, or order lifecycle event — the order just sat at `status="filled"` forever. Searched every Alpaca activities endpoint (~30 type codes), `/v2/orders`, `/v2/account/portfolio/history`, `/v2/positions`. Record exists nowhere. This is the kind of finding worth filing with Alpaca support if you encounter a similar discrepancy on another contract.
- **Legacy stop-loss policy cost ~$1,000–$2,500 across the bot's lifetime.** 5 contracts hit the pre-FC-010 `_check_call_stop_loss` (NVDA, AMD×2, IWM, AMZN). All five share the same shape: thin OTM call ($1.83–$3.20), stock ripped through strike in 1–8 days, stop-loss fired at ~75–80% loss, bought back at ~4× premium received. Direct realized loss: −$4,172. Net cost after partial recoveries from post-buyback re-writes: ~$1k–$2.5k. Useful baseline for future "should we add a stop-loss back?" discussions — current production has zero such losses since FC-010 disabled the policy on 2026-04-17.
- **The 4/15 AMD "roll" wasn't FC-006.** During investigation I initially attributed AMD's 4/15 buyback-and-write-higher-strike sequence to FC-006's rolling engine. It wasn't — it was the legacy stop-loss firing followed by the regular call_seller writing a new contract on the next scan. FC-006 is wired up (scheduler enabled, config `rolling.enabled: true`) but has fired *zero times* in production logs over the last 60 days. Trigger gates (`max_current_dte: 1`, `itm_trigger_ratio: 0.98`, `max_debit_pct_of_premium: 0.25`) are strict enough that real-world setups rarely match. Worth tuning or instrumenting with skip-reason logging if rolling is supposed to fire.
- **Real AMD wheel was profitable, not catastrophic.** Pre-FC-021 the dashboard showed AMD at −$17,319 (worst symbol). Post-fix: +$5,309 (3rd best symbol). Cycles broke down as: Cycle 1 −$1,925 (early loss from selling ITM calls below cost basis to escape a drawdown — by design), Cycle 2 +$535 (short cycle ending at the silent 1/16 exercise), Cycle 3 +$2,026 (long cycle held through Feb plunge, called away in April).

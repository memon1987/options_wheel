## Key Decisions & Rationale

- **Full-market-value add-back over the FC-020 dependency.** Disposal-based realized P&L (the audit's original framing) requires FIFO closed-lot re-pairing — exactly the FC-020 work this plan scoped out. Adopting the cash-ledger convention (Option A from the PM review) gets a correct MTM number from data that already exists; FC-020 remains the fix for *per-cycle* rows, and cycle aggregates exclude overlapping-lot symbols with disclosure rather than averaging known-wrong rows.
- **Total P&L keeps the headline tile; XIRR is the sub-line.** The PM review's point: with a single deposit, "money-weighted return" is marketing for the same CAGR — the bank-statement number is what every stakeholder trusts, so it leads.
- **Anomaly calendar from SPY bars, not the scheduler's own events.** A self-derived calendar is blind to total scheduler failure (the FC-006 roll engine fired zero times for weeks, unnoticed). A day with a SPY bar and zero scans is unambiguously a missed trading day.
- **Metrics banned, not just deprioritized:** blended per-contract win rates, annualized single-cycle returns, gross-premium-as-income, ACB summed into P&L, Sharpe/Sortino/beta on <12 months of negatively-skewed short-vol returns. The verification checklist greps for them.
- **Direct merge instead of a PR.** GitHub API access is disabled for this session (Claude GitHub App not connected for the org; MCP connector disconnected). The user explicitly requested the merge; a `--no-ff` merge commit preserves the branch as the review record, and both adversarial reviews + 365 green tests stand in for PR review. Re-connecting the GitHub App restores the normal PR flow.
- **FC-030 partially absorbed:** the drawdown-pause card satisfies its dashboard scope; the operator-alerting/escalation half stays open in the FC ledger. (Note: strategy-review-2026-05-07 §5's speculative FC-030/031 numbering is superseded by the FC ledger.)

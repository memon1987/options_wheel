## Discoveries

- **The earnings gate never existed.** Config read as live (`earnings.enabled: true`) but zero wiring on any trading path — the operator believed it was a key control. The AAPL day-of-earnings call write (07-30, 15:15 ET, 45 min before an AMC report) proved it.
- **Only AMZN matched the earnings-pop story**: GOOGL/AAPL gapped *down*; GOOGL's runaway was post-earnings momentum no gate touches. $2,706 of upside was being surrendered vs $533 premium collected on the open calls.
- **A credit-only roller can never rescue a deep-ITM pop** (AMZN: every strike-improving roll $1.2–1.7k debit) — the gate prevents the unrescuable; the roller monetizes the rescuable (GOOGL-class).
- **Alpaca cancels are queued** (`pending_cancel`): a single post-cancel re-read can report "no naked position" while three sells fill. Poll-to-terminal is mandatory.
- Alpaca Monitoring API: one log-match condition per policy (OR the filters); 4000-char documentation cap; patching needs `notificationRules.delete/update`.
- Off-hours IEX quotes are garbage on mega-caps (AAPL bid 287.82/ask 318.75) — the 1.05 spread-sanity guard is load-bearing.
- Subagent silent-death pattern (2 occurrences): no completion event, `TaskStop` says "no task found" — relaunch; watchdogs must use transcript-size growth, not mtime.
- Hook model warnings on subagents are parent-echoes — verify with `grep '"model":' <transcript>` (established standard; every stage this session verified on the correct tier).

## Key Decisions & Rationale (operator decisions — binding; do not relitigate)

1. **Floor = Alpaca `avg_entry_price`** (the UI number; broker-authoritative; auto-weighted across lots). Knowingly premium-netted (~one put premium below cash-paid); accepted because no tradeable strike falls in the gap on $2.50 grids — verified live for all four lots. **IWM $1-grid in-gap strikes are a permitted standing exception** (bounded ≤ one premium/lot, cycle-net ≥ 0), no audit machinery, by choice.
2. **Never net collected premium into the floor.** Premium is profit, not exit subsidy. ACB-style floors rejected on evidence: they ratchet (AMZN chain fell 246→224 as roll-down premium accrued, and would have licensed the −$3,500 disaster write). The economics agent's initial recommendation (broker basis, "loosest floor with cycle-net ≥ 0") was **rejected by the operator** — cycle-net = 0 means we made nothing.
3. **Below floor: hold uncovered until recovery. No pause gate** (FC-065 OQ-3): band analysis showed a pause gate's only marginal effect is blocking above-floor *profitable* writes. Legibility ships as decision-record labels (`underwater_pct`, `uncovered_days`). FC-033 → **Deferred** (not Closed) with lineage; reopen is operator-only on `uncovered_days` evidence.
4. **Delete the dead engine path rather than merge or revive it** (FC-068): production has voted for ten months; every incident in the FC-029/038/045/048/050/065 family came from remediating the unused half.
5. **FC-069 split from FC-068**: the sweep's two lead items (global position cap, earnings gate) are risk-policy revivals, not cleanup — they get their own plan review with operator sign-off.

- **The no-strike-in-the-gap predicate was already false:** IWM trades on a $1 grid; two puts held this week would have had in-gap strikes on assignment. "Revisit if the universe changes" had already failed unnoticed.
- Production runs a **stateless wheel**; `WheelStateManager` is fiction rebuilt per request. Production has **no global position cap, no per-ticker exposure cap, no earnings gate, no market-hours gate on /scan+/run**.
- `wheel_cycles` is corrupt as an audit: reconcile re-writes each assignment ~6×/day for 7 days (36/31/7 duplicate zero-gain rows verified).
- Every production `call_sale_executed` event logged zeroed economics (fixed in FC-065 P4 scope); `avg_entry_price` = assigning strike − put premium, verified against fills; OPASN rows carry NULL price — cash-paid lives on the OPTRD leg.
- Call limit pricing is blunt `mid × 0.95` while puts are spread-aware — the put-side improvement was never ported (own future FC).

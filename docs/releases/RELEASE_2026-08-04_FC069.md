- **Every operator decision executed exactly as signed off** — no card relitigated.
  Item 4 (earnings) was already live via FC-013 and item 13 via FC-078; both
  skipped as instructed. S4 dropped (item 1 flip).

  transfer-config listing** the SA cannot run: 30-day BQ audit logs show zero
  `bigquerydatatransfer` activity project-wide — activity-level evidence, stronger

  changed live event payloads for zero gain.

  execution order authorized it, and the window's intent (zero new rows) was
  satisfied by a 25-day observed quiet period plus a post-deploy live-cycle check.

## Discoveries

- **Puts are hardcoded to 1 contract per position** (`put_seller.py:99`) — the
  plan's own "sizer caps at 10 contracts" was falsified during the docs rewrite;
  the computed ceiling is only a feasibility gate. Calls size by shares (FC-038).
  The docs now state reality; revisiting the 1-contract choice is an open operator
  question as the account grows.
- **FC-079 (filed)**: the position-diff reconcile classifier uses
  `'P' in option_symbol` — call assignments structurally undetectable on that
  fallback path for AAPL/PFE/SPY/PG. Second site in the monitor's reconcile
  checks. S2/S6 tests deliberately use MSFT until it lands.
- `_ensure_all_tables()` re-creates any table in `_SCHEMAS` on cold start (71×
  in 30 days) — deleting the schema entry is load-bearing for any table drop.
- Reconcile loop-3's orphan-clearing branch is unreachable (loop 1 zeroes
  first) — pinned at 0 by test so a future fix is deliberate.
- July-2026 log emissions of "Put position added"/"Position removed" trace to the
  FC-032-demolished old backtester (rev 00276-viz) — recorded so future log greps
  don't misread the census.
- `options_wheel_logs.wheel_cycles` view rot: `strike_price`/`premium` NULL from
  every feeder that ever existed — retirement candidate (residual, surfaced).
- The S1 deploy break: a JSX comment in expression position failed the dashboard
  image build; builder and both reviewers had run pytest only. **Standing rule
  (now in docs/CLAUDE.md): `npx tsc --noEmit` before merging any `dashboard/`
  change.**
